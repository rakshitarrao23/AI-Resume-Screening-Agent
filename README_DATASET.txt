# Resume Screening Test Data

This package contains synthetic, fictional resume data created for testing an AI Resume Screening Agent.

Contents:
- job_description.txt
- resumes/ (10 PDF resumes)
- expected_test_notes.txt

The names, emails and phone numbers are fictional placeholders and should not be treated as real candidate information.

For the Rooman challenge, keep this dataset inside your project's `data/` folder.
